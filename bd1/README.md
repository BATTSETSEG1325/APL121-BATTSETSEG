# APL121 Бие даалт №1 — Code Quest

## Сэдэв №12: Тооны шидэт хүснэгт

Энэ программ нь хэрэглэгчийн оруулсан тооны үржүүлэх хүснэгтийг 1–10 хүртэл хэвлэнэ. Мөн тэгш/сондгой эсэхийг шалгаж, цифрийн нийлбэр болон урвуу тоог гаргана. Дараа нь гурван эерэг бүхэл тооны цифрийн нийлбэрийг харьцуулж, цифрийн нийлбэр хамгийн ихтэй тоог олно.

## Өөрийн тогтоосон дүрэм

* `n` нь 1–1,000,000 хүртэлх бүхэл тоо байна.
* Үржүүлэх хүснэгт 1-ээс 10 хүртэл хэвлэгдэнэ.
* Сүүлийн хэсэгт оруулах `a`, `b`, `c` тоонууд эерэг бүхэл тоо байна.
* Цифрийн нийлбэр тэнцсэн тохиолдолд эхэлж шалгасан тоог сонгоно: эхлээд `a`, дараа нь `b`, эцэст нь `c`.
* Урвуу тооны эхний тэгүүд хэвлэгдэхгүй. Жишээ нь `120`-ийн урвуу тоо `21` байна.

## Файлууд

* `quest.fprg` — Flowgorithm блок схемийн файл
* `flowchart.png` — блок схемийн зураг
* `pseudocode.md` — алгоритмын псевдокод
* `main.c` — C хэл дээрх программ
* `tests.md` — тестийн тохиолдлууд
